Your weekly routine.

Flyer Filler

  1. Add both Excel files. This week's REPUBLICA script and your latest Emails workbook.
  2. Build email rows. Check the Miami and Orlando tabs that were picked, then review both tables. Every cell is editable.
  3. Copy for Excel. Open the matching tab, select C3, and paste. The block fills C3:K21, including the valid-through date.

Know what to check

REVISE THISCould not be verified. Fix before pasting.

NEWFirst-time product. Add the link.

SCRIPTTaken from the script text. Check the wording.

Approval reply

When Yarelis or Niuvy reply with edits, paste the reply into Approval reply before building. Preview edits shows what will change; uncheck anything you don't want. Edits on BOGO Gate items are listed but don't affect the email.

Filler QA

Runs after every build. Run it again after editing cells to confirm everything passes.

Image QA

Add the proofs and reference images, then select Compare images. Start with the summary matrix. Large batches can take a few minutes, and matches still need a visual check.

Your saved session

Files and options are remembered in this browser as you add them. Next time, select Restore session to reload them, then swap in this week's files. Clear saved session removes everything saved.

Audit Log

Use Report a bug in the header, or the flag on any Miami or Orlando row, to note a problem. The tool attaches the version, files, tabs and row for you. Notes go to the Bug Log on SharePoint, and Copy for Claude turns them into a fix list.

Flyer Lookup

Search the master link catalog by UPC or product name. Imports and edits stay in this browser.
